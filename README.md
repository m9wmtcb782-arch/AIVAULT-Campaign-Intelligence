### 🧠 Project Vision

AIVAULT Campaign Intelligence 是一套以 AI 為核心的選區情報與公共政策決策平台。

系統每天追蹤選區公開資訊，協助分析：

- 選區每天發生的重要事件
- 地方新聞與公共議題
- 公共建設與市政問題
- 選區居民可能面臨的公共需求
- 政府目前的政策與執行情況
- 公開的政治人物與政黨政策動態
- 政策缺口與可能的改善方向
- 候選人可以直接推動、爭取或需要協調的事項
